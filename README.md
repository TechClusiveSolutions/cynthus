# Cynthus documentation

Design documents, engineering standards and shared tooling for the Cynthus Life platform.

- [`docs/engineering-standards.md`](docs/engineering-standards.md): how we write, test, review and merge code.
- [`docs/adr/`](docs/adr): architecture decision records.
- [`docs/architecture/web-app-conversion-plan.md`](docs/architecture/web-app-conversion-plan.md): moving the prototype
  web app onto the documented services.
- [`templates/repo/`](templates/repo): the CI, lint and pull-request files every service repository carries.
- [`tools/`](tools): test runner, test generators, mutation and inventory checks, and `bootstrap_repo.py`.

Work is tracked on the
[Cynthus Engineering Tracker](https://github.com/orgs/TechClusiveSolutions/projects/6).

Applying the **one-class-per-module** rule is an excellent choice for a mission-critical system like the Cynthus Life Ecosystem. It eliminates massive scroll lengths, simplifies your git diffs during collaborative code reviews, and makes your microservice routing paths incredibly predictable.

When combining Feature Slice Design (FSD) with the one-class-per-module constraint, directories naturally morph into structural containers (`packages`), and files (`modules`) represent individual, focused domain types.

Here is how we can adapt the namespace strategy to strictly enforce this layout.

## 4. Keeping it Clean: The API Facade Layer (`__init__.py`)

While having one class per file is perfect for development ergonomics, you don't want downstream consumers (`cynthus-api` or `cynthus-auth`) to write long, deep imports like `from cynthus.messaging.slices.clinical.events.clinical_signal_created import ClinicalSignalCreatedEvent`.

```python
    "ClinicalSignalCreatedPayload",

```

## 2. Pydantic Class Naming & Inheritance Layout

To align with Python naming conventions while preserving the explicit architectural metadata defined in Section 4 and 6 of your ADD, use an explicit **Suffix Strategy**:

* **`Base`**: Structural primitives or abstract base blocks.
* **`Payload`**: The mutable, inner domain-specific business data context.
* **`Event`**: The finalized, immutable global envelope variant binding a specific payload to the bus.

### `cynthus.messaging.shared.base`

This file declares the foundational building blocks for cross-cutting correlation and multi-tenant security tracking.

```python
# cynthus/messaging/shared/base.py
from datetime import datetime, timezone
from enum import Enum
from typing import Generic, TypeVar
from uuid import UUID, uuid4
from pydantic import BaseModel, Field, ConfigDict

PayloadT = TypeVar("PayloadT", bound=BaseModel)

class LifecycleAction(str, Enum):
    CREATED = "created"
    UPDATED = "updated"
    DELETED = "deleted"
    SNAPSHOT = "snapshot"

class SignalMessageBase(BaseModel):
    """Primal structural base for all standalone data interactions."""
    model_config = ConfigDict(
        frozen=True,
        populate_by_name=True,
        json_encoders={datetime: lambda dt: dt.astimezone(timezone.utc).isoformat()}
    )

class SystemIdentityMessageBase(SignalMessageBase):
    """Base structural model enforcing multi-tenant isolation contexts."""
    organization_id: str = Field(..., description="Corporate Tenant boundary identifier.")
    workspace_id: str = Field(..., description="Functional Isolation partition tracking key.")
    actor_id: str = Field(..., description="The unique system or user identity executing the shift.")

class CynthusGlobalEnvelope(SystemIdentityMessageBase, Generic[PayloadT]):
    """The immutable common spine published to cynthus-events-topic."""
    event_id: UUID = Field(default_factory=uuid4)
    event_type: str = Field(..., description="Dot-notated routing string (e.g., 'clinical.signal.created')")
    lifecycle_action: LifecycleAction
    correlation_id: UUID = Field(..., description="CrossServiceCorrelationGuid diagnostic tracer.")
    timestamp: datetime = Field(default_factory=lambda: datetime.now(timezone.utc))
    payload: PayloadT

```
